# Maya 2027.2 validation record

The reusable implementation was validated with Maya 2027.2 build 1839 and
the release archive recorded in `releases/2027.2/release.json`.

Validated behaviors were: Portage installation, `mayapy` startup, batch mode,
interactive GUI startup through XCB/Xwayland, Autodesk licensing after an
interactive sign-in, and Viewport 2.0 OpenGL initialization. The tested
optional component set was MayaUSD, Bifrost, LookdevX, and Substance for
Maya. Arnold was not claimed because it was not present in the tested payload.

The exact host GPU and Mesa versions are retained in the compatibility
document as evidence only; they are not installation requirements.
