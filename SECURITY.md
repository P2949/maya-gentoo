# Security

Report credential exposure, unsafe privilege behavior, installer path
traversal, shell injection, supply-chain/hash problems, or accidental
proprietary payload inclusion privately to the repository maintainer. Do not
publish Autodesk account tokens, cookies, passwords, private keys, or complete
unredacted Identity Manager/licensing logs.

Never work around licensing by bypassing Autodesk authentication. Never use
RPM force-installation, global library-path injection, or broad destructive
cleanup as a security workaround.
